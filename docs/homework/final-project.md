# Final project
Romain Ferrali & Paul Love

Feel free to use the starter template at
<https://github.com/recap-org/template-r-small> for a clean starting
setup.

In this project, you should find or construct some data, develop a
hypothesis, analyze the data to test that hypothesis, produce
publication-quality data visualizations, and carefully interpret your
results.

The project should be no less than 3 pages and include at least 2 data
visualizations. It should be turned in as a `.pdf` file, and the `.qmd`
file with the commented code for your analyses should also be submitted,
alongside with the raw data.

## Grading Rubric

I am looking for five key things in this assignment:

1.  Communicate to a non-statistical audience in a well-formatted and
    well-structured report (20%)
    - 0: The report is not well-formatted, and the writing is difficult
      to follow. The report is not accessible to a non-statistical
      audience.
    - 20%: the report is well-formatted, the writing is clear, easy to
      follow, in a magazine style, and accessible to a non-statistical
      audience, while also satisfying more technical readers.
      Specifically:
      - The report presents the context, the data, and the main
        hypothesis
      - The report presents the main results in a clear and accessible
        way, without relying on jargon.
      - Regression analyses are present, but relegated to the Appendix.
2.  Hypotheses are tranlsated to regressions (20%)
    - 0: No regression analyses are present, or the regression analyses
      do not correspond to the hypotheses being tested.
    - 20%: The report includes regression analyses that correspond to
      the hypotheses being tested. Those regressions are correctly
      specified, and provide multiple tests of the same hypothesis
      (e.g., different proxies for the same concept, specifications with
      and without control variables, etc.). The writing clearly explains
      which patterns in the regression results should uphold or
      contradict the hypotheses being tested.
3.  Regressions are correctly interpreted (20%)
    - 0: The report does not interpret the regression results, or the
      interpretation is incorrect.
    - 20%: The report correctly interprets the regression results,
      including the statistical significance of the results, and their
      substantive implications.
4.  High-quality data visualizations make one key point and have all
    necessary elements (titles, axis labels, legends, etc.) to be
    understandable on their own. (20%)
    - 0: The report does not include any data visualizations, or the
      data visualizations are of low quality (e.g., missing axis labels,
      titles, legends, etc.) and do not make a clear point.
    - 20%: The report includes three publication-quality data
      visualizations that each make one key point and have all necessary
      elements (titles, axis labels, legends, etc.) to be understandable
      on their own. It is clear from the text or the caption whether the
      data visualizations are based on raw data or regression results
      (or both).
5.  Discussion of causality (20%)
    - 0: The report does not discuss the causal limitations of the
      analyses, or the discussion is incorrect.
    - 20%: The report correctly discusses the causal limitations of the
      analyses, including potential confounders, reverse causality, and
      other threats to causal inference. The report also discusses what
      can and cannot be concluded from the analyses in terms of
      causality.
